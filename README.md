# OOAD RBAC 课程项目

本项目按 C1（RBAC0）、C2（RBAC1）、C3（RBAC3）三个阶段交付。阶段范围、开发进度和验收要求见 [项目需求总览](./项目需求总览.md)。

## 当前进度

C1（RBAC0）已完成并通过本地端到端验收。交付内容包括结构化后端、权限管理平台、业务模拟前端、OpenAPI、陈氏 ER 图和详细设计。C2（RBAC1）已从 C1 基线 `0e8778e` 派生面向功能和面向对象两套后端，并完成本地功能联调。两版共用契约与验收数据，通过一个前端站点的 `/func/` 和 `/oo/` 分别演示。阶段范围包括角色继承、实时授权、三份 Excel 全量浏览和公司／部门申请 CRUD。现有 16 项验收场景及 42 张设计图，核心实现已有历史测试证据，后端代码与模块说明整理已完成；测试重做及 JaCoCo 归档已完成，后端48/52项和浏览器23项通过；三种模型比较及内存小样 10 项测试已完成；GRASP 专项已完成，项目总结和部署交接已交付，答辩稿仅本地保留，镜像/网关/stack 与脚本已交付并通过本机容器验证；Apifox 集群环境和课程 Swarm 验收待完成，最终文档待集群结果回填，见 [C2 收尾清单](<./c2-rbac1-面向功能+面向对象（后端+部分前端）/收尾清单.md>)。
