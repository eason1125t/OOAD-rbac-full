# OOAD RBAC 课程项目

本项目按 C1（RBAC0）、C2（RBAC1）、C3（RBAC3）三个阶段交付。阶段范围、开发进度和验收要求见 [项目需求总览](./项目需求总览.md)。

## 当前进度

C1（RBAC0）已完成并通过本地端到端验收。交付内容包括结构化后端、权限管理平台、业务模拟前端、OpenAPI、陈氏 ER 图和详细设计。C2（RBAC1）已确定阶段需求和开发方案，计划从 C1 基线 `0e8778e` 派生面向功能和面向对象两套后端。两版共用契约与验收数据，通过一个前端站点的 `/func/` 和 `/oo/` 分别演示。阶段范围包括角色继承、实时授权、三份 Excel 全量浏览和公司／部门申请 CRUD。
