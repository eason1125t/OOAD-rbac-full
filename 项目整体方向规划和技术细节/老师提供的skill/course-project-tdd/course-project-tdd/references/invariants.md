# 必须被测试覆盖的业务不变量（本项目）

来源：`docs/requirements.md`（R 编号）与 `api/openapi.yaml`（错误码）。**每一条都要有先红后绿的测试**；领域规则测纯逻辑，库约束测真实数据库。

| 需求 | 不变量 | 期望行为（含错误码） | 建议测试名（先红） |
|---|---|---|---|
| R8 | 选课名单导入可重复 | 同一份 Excel 再导一次：学号已存在的只加入本班、不重复建号、组队信息不变 | `R8 重复导入同一份名单不重复建号` |
| R9 | 学生账号自动创建 | 名单里的学号系统里没有 → 建账号，初始密码 = 学号后六位 | `R9 导入后系统里没有的学生得到账号` |
| R10 | 首次登录强制改密 | 初始密码登录后 `mustChangePassword = true`，未改密不能做别的操作 | `R10 首次登录必须改密` |
| R13 | 同一学生同一课程只能在一个组 | 已在组里再加入另一个组 → 冲突 `ALREADY_IN_GROUP` | `R13 同一课程只能属于一个组` |
| R14 | 空组自动解散 | 最后一名成员退出 → 小组记录消失 | `R14 最后一人退出后小组解散` |
| R15 | 人数上下限 | 学生建组/加入时按上下限校验（`GROUP_SIZE_OUT_OF_RANGE`）；**教师调整不受限** | `R15 学生受上下限约束而教师不受` |
| R16 | 组队截止后学生侧冻结 | 截止后建组、加入、退出都被拒 | `R16 截止后学生侧操作被拒` |
| R17 | 跨班归属判定 | 顺序：① 人数多的班 ② 当前负责小组数少的班 ③ 组长所在班；**平局按成立时间依次判，每判完一组即时更新计数** | `R17 平局按成立时间依次判定并即时更新计数` |
| R19 | 批改型只有小组分 | 批改型里程碑没有个人分；驳回时 `score` 可为空 | `R19 批改型没有个人分` |
| R20 | 口试时段的预约与删除 | 时段约满后其他组不能再选（`SLOT_FULL`）；教师删除被预约的时段 → 该组回到「未预约」且**预约次数退还** | `R20 删除被预约的时段后退还预约次数` |
| R21 | 口试重试与上限 | 每组最多口试 2 次；两次驳回 → 小组分与个人分都记 0 | `R21 两次驳回记 0 分` |
| R23 | 预约次数上限 | 每次成功约到消耗 1 次；**取消或改约不退还**；超过上限拒绝（`BOOKING_LIMIT_REACHED`） | `R23 取消后次数不退还` |
| R23b | 取消预约的时间窗 | 进入「口试前 X 小时」（X 来自里程碑定义）后，取消与改约都被拒 `CANCEL_WINDOW_CLOSED`；X = 0 表示不限制 | `R23b 进入时间窗后不能取消预约` |
| R24 | 里程碑权重 | 权重合计必须等于 100；**允许保存中间态**，但发起检查前必须是 100（`WEIGHT_SUM_NOT_100`） | `R24 权重合计不为 100 时不能发起检查` |
| R25 | 最终成绩 | 每个里程碑得分 ÷ 该里程碑满分 × 100 × 权重，求和；5 分制按满分 5 折算；未评的里程碑按 0 计并标 `pending` | `R25 82 分权重 20% 得 16.4` |
| R6b | 已完成的里程碑被锁 | 只能改权重 / 成绩构成 / 计分制；改名称、截止时间、检查方式或删除 → `MILESTONE_DONE_LOCKED`；该里程碑的提交材料也锁定 | `R6b 已完成的里程碑不能改名称与删除` |
| R35 / R41 | 有里程碑记录后不能移除任课教师 | 移除任课教师 → `MILESTONE_RECORDED`（**仍然可以增加**；课程组长可以随时更换） | `R41 有里程碑记录时只能增加任课教师` |
| R3b | 有小组的教学班不能删 | 删除 → `CLASS_HAS_GROUPS`；还没有小组的班可以删 | `R3b 有小组的教学班不能删除` |
| R35 | 有学生的课程不能删 | 删除 → `COURSE_HAS_STUDENTS`；学生数为 0 的课程可删 | `R35 有学生的课程不能删除` |
| R34 | 学期删除的两道门槛 | 有课程 → `TERM_HAS_COURSES`；是当前学期 → `TERM_IS_CURRENT` | `R34 当前学期不能删除` |
| R40 | 仍在担课的教师不能删 | 任何学期里担任课程组长或任课教师 → `TEACHER_IN_USE` | `R40 还在担课的教师不能删除` |
| R29 | 关键操作留审计 | 改分、改分组、改里程碑、改名单都要落审计（谁、何时、改前改后），学生不可见 | `R29 改分写入审计日志` |
| 接口通用 | 所有列表接口分页 | 查询 `page` + `pageSize`，响应带 `page`/`pageSize`/`total` | `列表接口都返回 total` |

## 边界与错误也要有用例

- 截止时间边界：恰好到点、刚过一秒。
- 幂等：重复提交、重复导入、重复删除。
- 权限：任课教师访问别人教学班 → `FORBIDDEN`；学生调用教师接口 → `FORBIDDEN`；被禁用教师登录 → 提示已禁用。
- 空状态：没有小组、没有提交、没有时段、没有学生时接口返回空列表而不是报错。
