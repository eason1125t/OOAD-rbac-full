# 数据与初始化

C2 阶段进度以 [开发方案](../../../../../开发方向细节.md) 和 [收尾清单](../../../../../收尾清单.md) 为准，以下 C1 文档作为沿用功能的基线参考。

状态：已实现，待课程库复验。参见 [C1 基线开发规划](<../../../../../../c1-框架-rbac0-结构化+面向功能/后端开发规划.md>)。

## 应有功能

负责 Flyway、JPA 表映射、三份 Excel 导入、演示组织与分配初始化。

## 实现方式

启动时迁移并校验 JPA。显式执行 `--import-excel` 或 `--init-demo`。保留源字段和空值，唯一匹配才关联组织。相同输入可重跑，冲突整批回滚。V1–V5 依次建立基础表、保留原表上级、增加登录账号与默认系统、增加模拟申请并支持组织重授。C2 追加 V6 继承关系与图写锁、V7 申请人及生命周期字段、V8 系统申请查看权限定义；历史申请保留可空申请人。显式演示初始化支持八个账号，重跑保留已有继承改动与组织策略。

## 代码入口

[InitializationCommand](InitializationCommand.java) 解析启动参数，[InitializationService](InitializationService.java) 管理导入事务，[WorkbookReader](WorkbookReader.java) 读取工作簿。Flyway 脚本位于 [resources/db/migration](../../resources/db/migration)。

## 与其他模块的关键联系

为登录提供员工，为组织与员工、角色与权限和授权配置提供基础记录。与业务模块分别维护登录凭据和模拟申请。

## 验收

本地已验证 Flyway、重复导入和事务回滚。课程库待核对迁移历史、三表计数及待匹配员工。本机通过显式初始化命令准备演示数据。C2 Compose/Swarm 初始化与课程原表只读挂载方案仍待部署交付，不将 C1 的容器配置视为已适配完成。
