# C2 三模型比较

本目录集中保存三种模型的设计、比较结果、满血内存小样及新增图件。用户于2026-11-19确认采用本项目的满血工作定义；它不是通用架构等级，也不预设比充血更优。

- [设计方案](./设计方案.md)：共同用例、边界与已确认范围。
- [三模型设计](./三模型设计.md)：真实func/oo与满血小样的类、调用顺序和职责。
- [比较结果说明](./比较结果说明.md)：证据、测试、取舍、结论及局限。
- [小样源码](./小样/src/main/java/comparison/FullRoleHierarchy.java)、[构建配置](./小样/pom.xml)。
- [图件索引](./图件/README.md)：复用四张真实实现图，新增两张满血小样图，保留原生StarUML图源和PNG/SVG。
- [独立测试及记录](../测试/模型比较/README.md)：测试源码位于统一测试目录；不混入正式后端48/52项统计。

在本目录执行：

```powershell
mvn -f 小样/pom.xml test
java -cp 小样/target/classes comparison.ExampleMain
./图件/export.ps1
```

需要Java21、Maven，出图另需本机StarUML。示例输出依次为ADDED、UNCHANGED、2，分别表示首次新增、重复幂等和可达角色数量。只使用合成数据，不接数据库、Redis或HTTP。图件沿用现有生成工厂；StarUML试用水印保留。

本轮没有改变两套正式后端、OpenAPI或Flyway。小样不证明数据库并发、组织重授完整性和HTTP授权；这些仍查正式测试报告。GRASP 专项现已完成，见 [grasp与项目](../grasp与项目.md)；[项目总结](../项目总结.md)、`答辩文档.md`（本地待完善，暂不上传） 和 [部署交接说明](../部署交接文档.md) 现已形成，部署配置已交付，下一步完成实际集群验收。
