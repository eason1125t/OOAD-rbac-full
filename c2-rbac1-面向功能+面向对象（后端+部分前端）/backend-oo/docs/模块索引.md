# C2 面向对象版后端模块索引

本版使用独立 Maven 工程。功能包直接放在 `src/main/java` 下，每个功能包的 README 记录实现、依赖和验收。[启动入口](../src/main/java/app/RbacApplication.java) 负责加载同级包的 Spring 组件、JPA 实体和 Repository。

| 模块 | 代码与说明 | 职责 |
| --- | --- | --- |
| 数据与初始化 | [initialization](../src/main/java/initialization/README.md) | 演示数据、Excel 导入与迁移 |
| 登录与会话 | [authentication](../src/main/java/authentication/README.md) | 账号、Redis 会话与工作区导航 |
| 组织与员工 | [organization](../src/main/java/organization/README.md) | 公司、部门与员工管理 |
| 角色与权限 | [rolepermission](../src/main/java/rolepermission/README.md) | 角色、运行时权限、继承维护与 Excel 权限清单 |
| 授权配置 | [assignment](../src/main/java/assignment/README.md) | 两类授撤权与组织权限策略 |
| 实时授权 | [authorization](../src/main/java/authorization/README.md) | Spring Security 路由保护与统一判权 |
| 业务模拟 | [simulation](../src/main/java/simulation/README.md) | 系统目录、查看权限、申请生命周期与实时审批 |
| 接口契约与验收 | [contract](../src/main/java/contract/README.md) | 统一错误、日志与集成验证 |

顶层按功能包组织。角色继承经 RoleInheritanceStore 端口和 RoleHierarchy 领域对象协作；申请模块按应用 Service、port、domain、infrastructure 分配职责。登录、组织策略等模块仍沿用 C1 Service/JPA，不描述为已全面完成 DDD 改造。请求和响应按需使用 `dto`、`vo` 子包。角色与权限定义在 `rolepermission`，管理端共用的 HTTP 入口和用例编排在 `organization`。测试位于 [src/test/java](../src/test/java)，应用配置和 Flyway 脚本位于 [src/main/resources](../src/main/resources)。

运行方式见 [C2 README](../../README.md)，实施范围见 [C2 开发方案](../../开发方向细节.md)。[C1 部署说明](<../../../c1-框架-rbac0-结构化+面向功能/部署运行说明/README.md>) 仅作为基线参考，C2 的双版镜像、Compose/Swarm 配置和集群验证尚未交付。代码与模块说明的逐文件整理及测试重做见 [收尾清单](../../收尾清单.md)；现有测试位置保留，后续统一交付到 C2 的 `测试/`，并归档 JaCoCo 结果图及命令和输出 TXT。
