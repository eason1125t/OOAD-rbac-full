# C2 面向对象版后端模块索引

本版生产源码共 106 个 Java 文件，清单见 [源码索引](源码索引.md)。模块 README 说明真实核心函数、执行步骤、调用与被调用、事务/失败边界及技术。启动与测试环境见 [C2 README](../../README.md)。

| 模块 | 说明入口 | 核心职责 |
| --- | --- | --- |
| app | [启动与装配](../src/main/java/app/README.md) | 扫描组件、实体与仓储，选择 Web 或显式初始化 |
| initialization | [原表与演示初始化](../src/main/java/initialization/README.md) | POI 解析、来源匹配、原子导入和幂等场景 |
| authentication | [登录与工作区](../src/main/java/authentication/README.md) | 独立账号校验、Bearer JWT、Redis登录/严格刷新/撤销、Cookie CSRF及工作区 |
| organization | [组织及管理用例](../src/main/java/organization/README.md) | 正式树/最小员工目录及管理查询维护、范围、分页、脱敏和引用保护 |
| rolepermission | [角色权限与继承](../src/main/java/rolepermission/README.md) | 同归属图、环路拒绝及双向闭包 |
| assignment | [分配与组织策略](../src/main/java/assignment/README.md) | 直接分配、增量授权、停用/重开和同源重授 |
| authorization | [请求安全与实时授权](../src/main/java/authorization/README.md) | 过滤器和统一判权，读取当前 MySQL 关系 |
| simulation | [业务申请](../src/main/java/simulation/README.md) | 八类操作、状态竞争和提交后审计 |
| contract | [契约、错误与日志](../src/main/java/contract/README.md) | 统一错误、AOP 方法日志、CloneFactory 和测试入口 |

对象版的明确领域边界是 `RoleHierarchy` 和申请模块的 `domain/port/infrastructure`。申请应用服务依赖三个业务端口，由领域对象维护状态；继承存储也经端口。登录、组织策略等仍保留 C1 Service/JPA，不能描述为全面 DDD。

共享契约见 [OpenAPI](../../api/openapi.yaml)，成对 UML 及 GRASP 现有说明见 [设计目录](../../docs/design/README.md)。本次整理记录见 [后端整理说明](../../docs/项目总结.md)。GRASP 专项见 [grasp与项目](../../docs/项目总结.md)；[项目总结](../../docs/项目总结.md)、`答辩文档.md`（本地待完善，暂不上传） 与 [部署交接](../../部署/README.md) 已形成；剩余配置与集群实测按收尾清单推进。
