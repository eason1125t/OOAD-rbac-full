# 三模型比较小样测试

独立验证满血内存小样，结果不混入正式后端48/52项。代码与设计位于 [三模型比较](../../三模型比较/README.md)，测试源为 [FullRoleHierarchyTest](../模型比较/java/comparison/FullRoleHierarchyTest.java)。

## 实际执行

1. 先写合法新增测试，以可编译骨架运行；预期正常新增，实际UnsupportedOperationException，JUnit记为1项断言失败、0项错误：[RED.txt](../模型比较/RED.txt)。
2. 实现领域协作并补充边界，最终10项通过，零失败、错误和跳过：[GREEN.txt](../模型比较/GREEN.txt)。
3. [命令与环境](../模型比较/命令.txt)、[命令行示例输出](../模型比较/演示输出.txt)、[Surefire原始报告](../模型比较/TEST-comparison.FullRoleHierarchyTest.xml)。

仅首条新增行为记录了RED，不把后加测试或出图校验失败说成独立TDD RED。初始API骨架随后改为两个端口注入，测试断言仍观察新增和存储关系。没有新增mock调用次数断言。

## 十项行为

合法新增及重复幂等；自继承不保存；直接及传递闭环不保存；同向直达边合法；菱形闭包/逆向影响及空根；跨归属与越权；缺失角色及停用；装载副本隔离；保存失败不产生边；策略不可篡改快照。

内存只验证夹具规则，不验证数据库悲观锁、事务回滚、完整组织重授和HTTP身份。例外原因是小样本地异常，不构成新API错误码。正式功能和并发证据仍见 [C2真实执行报告](执行报告.md)。

## 断言与范围

| 测试方法 | 可观察结果 |
| --- | --- |
| addsAndKeepsIdempotent | 合法新增一条边，重复不增边 |
| rejectsSelf / rejectsCycles | 自继承、直接环和传递环拒绝且存储不变 |
| acceptsShortcut | 已有同向传递路径时仍允许直达边 |
| expandsDiamond | 菱形闭包去重，逆向影响含全部上游，空根返回空集 |
| rejectsInvalidScope | 跨归属和越权拒绝且存储不变 |
| rejectsMissingAndDisabled | 角色缺失和策略停用夹具拒绝且存储不变 |
| isolatesLoadedData | 装载副本修改不影响存储 |
| preservesGraphOnSaveFailure | 保存抛异常后未新增关系 |
| rejectsPolicyMutation | 策略不能篡改快照，存储不变 |

测试标题中的 C2 编号表示关联规则，不能据此将内存夹具视为该编号的完整验收。并发成环、组织停用重授和 HTTP 会话撤权仍查正式后端报告。
