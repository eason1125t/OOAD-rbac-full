# C2 开发方向细节 · RBAC1

状态：阶段方案，待 C1 验收基线和课程口径确认。参见 [阶段需求与验收](./阶段需求与验收.md) 和 [C1 后端开发规划](<../c1-框架-rbac0-结构化+面向功能/后端开发规划.md>)。

## 复用 C1

从同一个 C1 验收版本派生面向功能与面向对象两套后端，分别迁移到 `ooad_rbac1_func`、`ooad_rbac1_oo`。两版共用接口契约及验收数据，延续统一登录、默认工作区、系统下拉、组织范围和审批接口。

## 新功能及依赖

| 模块 | 扩展 |
| --- | --- |
| 数据与初始化 | 追加角色继承关系迁移，保留 C1 员工、角色、权限与组织数据 |
| 角色与权限 | 增加继承关系查询、添加、移除及有效权限查询。定稿继承方向、组织范围和并发防环策略 |
| 实时授权 | 展开直接和传递继承，汇总并去重权限，沿用组织隔离、停用优先和实时生效 |
| 契约与验收 | 两版回归 C1 并共同验证自继承、循环继承、传递继承、多路径去重及移除唯一授权路径 |

面向功能版沿读取、环路校验、写入和权限计算组织步骤。面向对象版由应用 Service 协调用例和事务，领域模型或领域 Service 处理层级不变量，Infrastructure 实现持久化端口。

## 交付与待确认
