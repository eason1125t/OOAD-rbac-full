# C2 开发规划与进度

更新：2026-11-22。本文件统一维护开发范围、收尾状态和后续方向。功能规则见 [阶段需求](阶段需求与验收.md)，讲解见 [项目总结](项目总结-整理前.md)，运行见 [C2 首页](入口说明-整理前.md)，部署见 [部署说明](../../部署/归档/部署说明-整理前.md)。

## 当前基线

- 一个共用前端、func/oo 两套独立后端；两版共用 OpenAPI，分别连接自己的库和JWT登录命名空间。
- 已实现 RBAC1 继承、有效权限、实时撤权、组织范围内权限停用/重开/同源重授、申请生命周期和课程 Excel 浏览。
- “组织停用”在当前实现中指组织范围内某项权限停用；不宣称已有组织整体 enabled 字段或任意层级的完整策略继承。
- OO 改造范围是角色图和申请领域/端口，认证与部分授权仍沿用 Service/JPA；保留 CloneFactory 与两版设计差异。
