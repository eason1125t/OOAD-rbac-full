## 当前状态

- 最新完整本机后端 func 194、oo 198 项通过，完整浏览器 51 项通过，包含原表全量摘要核对。结果、覆盖率和范围统一看测试说明。
- 本机已成套切换 JWT：前端 http://127.0.0.1:5173/，后端 18181/18182；旧 Session 不延续，用户重新登录。
- Spring Security 和 Redis 保留，Spring Session 已移除；JWT 只提供身份，独立 sid 支持在线撤销，权限实时计算，不使用 tokenVersion。
- Apifox C2 模块主契约已同步。“已对接 API 契约”指本项目功能和接口行为完成接入，不代表跨项目系统联调、CORS 或课程 Swarm 已验收。
- Git 提供源码、测试、契约、图件与脱敏证据。原表、SQL 备份、真实凭据、私钥、本机配置、构建缓存和待删除文件不随仓库交付。

本机管理使用 PowerShell 7：`./部署/local.ps1 -Action Status`，Start/Stop 和新机器配置见部署说明。测试不作为常驻服务。
