# C1 本地验收记录

验收使用本机隔离 MySQL 库 `ooad_rbac0_excel_review`、独立 Redis 会话命名空间及回环地址。实际 Excel 未进入版本库。两次导入使用同一原表，结果一致。管理员登录和业务模拟使用合成演示账号。

## Excel 与页面

| 范围 | 原表记录 | 验收结果 |
| --- | ---: | --- |
| 员工管理 | 10,000 | 全部分页返回与原表字段匹配。电话在服务端脱敏，54 条待匹配记录保留源字段。 |
| 部门目录 | 111 | 全部分页返回与原表三列匹配，根组织的空上级和分公司的原表上级保留。 |
| 权限管理的 Excel 原表清单 | 359 | 全部分页返回与原表九列匹配，系统和模块的合并值展开，空动作保留。 |

逐页从实际浏览器会话读取 API 并进行字段比对，另在三个目录核对首屏表格渲染。测试库还含 4 条合成员工、2 条合成部门记录。合成公司管理员可见其两个下属部门，合成部门管理员只看到本部门。实际导入中归类为公司的原表行也进入部门对照目录，范围仍按组织 ID 筛选。

## API 和结构化设计

- OpenAPI 通过 YAML 解析，35 组 HTTP 方法与路径与 Controller 映射逐项一致，操作 ID 唯一，组件引用有效。
- 浏览器验证申请首次审批返回 200，同一申请在另一页重复提交返回 `409 REQUEST_ALREADY_APPROVED`，页面显示鉴权通过、执行失败。
- `mvn verify` 的 30 项测试全部通过，覆盖作用域、同会话授撤权、组织停用与重授、会话日志和 CloneFactory 映射对应的 API 字段。
- 前端 TypeScript 检查和生产构建通过。Playwright 在生产构建上验证角色维护、两类直接分配、组织停用／重新开放／重授，以及同一员工会话在角色被撤后收到 403 且审批未执行。
- 隔离 Compose 实例启动后端、MySQL 8.4.7 与 Redis，Flyway V1–V5 迁移成功。分别断开 MySQL 和 Redis 时，审批返回对应的 503，申请仍为待审批。
- [结构化详细设计](./详细设计.adoc) 已渲染复核，归档权限分配、撤销、实时鉴权三张 SVG。既有模块结构和陈氏 ER 图见 [数据库设计](./数据库设计.adoc) 及 `design/`。
