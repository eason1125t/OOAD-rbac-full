# C1 组织权限策略接口

三个入口仅供超级管理员使用，均要求登录及 CSRF。业务系统与权限码共同定位动作。

| 方法与路径 | 行为 |
| --- | --- |
| PUT `/api/organizations/{organizationId}/business-systems/{systemCode}/permissions/{permissionCode}/disabled` | 停用动作并清除受影响的重授 |
| DELETE 同一路径 | 重新开放已停用的动作，恢复超级管理员默认操作权 |
| PUT `/api/organizations/{organizationId}/business-systems/{systemCode}/permissions/{permissionCode}/regrants/{roleId}` | 为已重新开放的范围显式重授指定角色 |

提交成功及幂等重试返回 204。组织、系统、权限或角色不存在返回 404 `RESOURCE_NOT_FOUND`。角色与权限关系缺失、组织仍停用或尚未经过重新开放时，重授返回 409 `ASSIGNMENT_CONFLICT`。超出角色归属范围或无管理资格时返回 403 `PERMISSION_DENIED`。非法路径参数返回 400 `VALIDATION_FAILED`。

例如工程部原有两个审批角色，重新开放后只有显式重授的角色可以恢复该范围的审批。完整范围与验收见 [组织权限停用与重新开放](../docs/组织权限停用与重新开放.md)。
