# 接口契约与验收

状态：持续维护。参见 [C1 后端开发规划](../../../../后端开发规划.md)。

## 应有功能

负责 OpenAPI、统一错误、分层日志、集成测试和演示验收。

## 实现方式

以 C1 的 `api/openapi.yaml` 记录路径、权限、会话与错误。使用 Logback 和统一分层日志。按需求编号测试成功、失败、事务回滚和同会话实时生效。集成测试使用独立 MySQL / Redis，JaCoCo 用于检查实际执行路径。

## 与其他模块的关键联系

接入所有模块的验收样例。Apifox 以同一契约联调。C2、C3 两种后端复用数据、请求和预期结果。

## 验收

检查 401、403、404、409 与基础设施错误。提交测试结果和运行说明，C2 补充 Swarm 与日志验收。
