# 登录与会话

状态：待接口详细设计。参见 [C1 后端开发规划](../../../../后端开发规划.md)。

## 应有功能

负责统一登录入口、当前身份、退出、CSRF 和 Redis 会话。登录结果包含用户导航所需信息。

## 实现方式

账号关联员工，密码使用 `PasswordEncoder` 哈希。会话保存可信员工 ID。使用同源 Cookie，写请求需 CSRF 令牌。员工停用后，从下一次受保护请求起拒绝旧会话。演示测试凭据只在显式启用的演示环境里初始化。

## 与其他模块的关键联系

向实时授权传入可信员工 ID，由实时授权提供可用工作区。组织与员工模块负责停用和归属，业务模拟提供系统记录和默认项信息。

## 验收

正确账号登录、错误凭据和待匹配员工拒绝、退出和过期失效、停用后的旧会话拒绝、CSRF 缺失拒绝。
