# 角色与权限

状态：待开发。参见 [C1 后端开发规划](../../../../后端开发规划.md)。

## 应有功能

负责角色和运行时权限定义的 CRUD，以及 Excel 功能权限清单的只读查询。

## 实现方式

业务权限按系统与权限码标识。全局共享定义由超级管理员维护，局部定义按归属校验。角色或权限仍被分配时拒绝删除，先解除关系。清单原动作文本和空值用于展示。

## 与其他模块的关键联系

向授权配置提供可选角色与权限定义，实时授权读取分配和定义。C2 新增继承关系，C3 新增约束配置。

## 验收

验证相同权限码在不同系统隔离，跨组织定义不可改，删除被引用的定义有稳定错误。
