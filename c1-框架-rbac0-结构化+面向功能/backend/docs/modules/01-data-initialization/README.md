## 应有功能

负责 Flyway、JPA 表映射、三份 Excel 导入、演示组织与分配初始化。

## 实现方式

启动时迁移并校验 JPA。显式执行 `--import-excel` 或 `--init-demo`。保留源字段和空值，唯一匹配才关联组织。相同输入可重跑，冲突整批回滚。现有 V1/V2 保留，后续字段以追加迁移交付。

## 与其他模块的关键联系

为登录提供员工，为组织与员工、角色与权限和授权配置提供基础记录。与业务模块分别维护登录凭据和模拟申请。
