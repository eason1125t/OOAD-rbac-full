# 业务模拟

状态：待开发。参见 [C1 后端开发规划](../../../../后端开发规划.md)。

## 应有功能

负责可进入系统所需的业务目录、预置申请、申请列表和审批。

## 实现方式

业务系统由初始化提供。使用稳定系统编码作为路由参数。审批从申请记录确定系统，先判权，再在事务内更新待审批状态。已审批返回业务冲突。预置多条申请用于逐次验证授撤权。

## 与其他模块的关键联系

给登录与实时授权提供系统及组织归属，调用实时授权检查准入和审批。C2、C3 沿用同一审批入口和响应。

## 验收

验证默认系统和下拉导航能正确访问，对有权系统才可查询和审批，并区分鉴权失败与业务冲突。
