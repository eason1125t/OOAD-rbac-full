# 实时授权

状态：待开发。参见 [C1 后端开发规划](../../../../后端开发规划.md)。

## 应有功能

负责管理端准入、管理范围、业务系统准入、业务操作权限和组织停用。

## 实现方式

Spring Security 在固定入口检查登录和对应权限，业务 Service 补充资源范围。业务判权使用会话员工 ID、服务端解析的业务系统、目标动作及 MySQL 最新关系。组织停用优先，超级管理员拥有仍开放操作的全局权限。

## 与其他模块的关键联系

被登录、组织与员工、角色与权限、授权配置及业务模拟调用。直接读必要的 Repository，避免回调调用方的 Service。C2 增加继承展开，C3 增加约束和可选角色激活判断。

## 验收

跨部门专属系统拒绝，同码权限按系统隔离，多路径撤销与超级管理员停用规则正确。
