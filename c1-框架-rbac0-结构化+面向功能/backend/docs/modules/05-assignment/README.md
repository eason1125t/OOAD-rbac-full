# 授权配置

状态：待开发。参见 [C1 后端开发规划](../../../../后端开发规划.md)。

## 应有功能

负责员工—角色、角色—权限、组织权限开放及停用。

## 实现方式

两类关联用 PUT/DELETE 表达授予和撤销，事务内处理替换并由组合键防重。检查关系两端与可授予范围。管理员离职保留历史分配。超级管理员停用时按组织、系统和权限生效。重新开放后显式重新授予。

## 与其他模块的关键联系

依赖角色与权限定义及员工归属，调用实时授权校验操作者能力。实时授权读取提交后的配置。共享角色跨组织时，停用和重新授予只影响目标范围，不能直接删除仍供其他组织使用的共享关系。范围内显式重新授予的具体存储方式在该模块详细设计中定稿。

## 验收

同会话授撤权即时生效，越权操作回滚，停用覆盖多条路径，重新开放后旧授权不会自动恢复，其他组织不受影响。
