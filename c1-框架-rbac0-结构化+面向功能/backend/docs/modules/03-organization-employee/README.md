# 组织与员工

状态：待开发。参见 [C1 后端开发规划](../../../../后端开发规划.md)。

## 应有功能

负责公司、部门目录的只读查询，员工新增、查询、编辑、停用和待匹配员工归属。

## 实现方式

管理员可在其管理范围内维护员工。列表筛选、计数和分页均应用同一范围。变更归属检查原组织、目标组织与现有角色分配。员工删除表现为停用，保留历史关联。组织目录保留 Excel 上级展示字段，鉴权按正式组织 ID。

## 与其他模块的关键联系

依赖数据初始化的公司和部门记录，依赖实时授权的范围校验。员工归属和启用状态供登录、授权配置及业务系统准入使用。

## 验收

部门目录按三列验收，普通员工和跨范围管理员的请求被拒绝，停用立即影响登录及后续受保护请求。
