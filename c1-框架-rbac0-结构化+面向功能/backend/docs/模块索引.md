# C1 后端模块索引

C1 使用单 Maven 工程。功能包直接放在 `src/main/java` 下，每个功能包的 README 记录实现、依赖和验收。[启动入口](../src/main/java/app/RbacApplication.java) 负责加载同级包的 Spring 组件、JPA 实体和 Repository。

| 模块 | 代码与说明 | 职责 |
| --- | --- | --- |
| 数据与初始化 | [initialization](../src/main/java/initialization/README.md) | 演示数据、Excel 导入与迁移 |
| 登录与会话 | [authentication](../src/main/java/authentication/README.md) | 账号、Redis 会话与工作区导航 |
| 组织与员工 | [organization](../src/main/java/organization/README.md) | 公司、部门与员工管理 |
| 角色与权限 | [rolepermission](../src/main/java/rolepermission/README.md) | 角色、运行时权限与 Excel 权限清单 |
| 授权配置 | [assignment](../src/main/java/assignment/README.md) | 两类授撤权与组织权限策略 |
| 实时授权 | [authorization](../src/main/java/authorization/README.md) | Spring Security 路由保护与统一判权 |
| 业务模拟 | [simulation](../src/main/java/simulation/README.md) | 系统目录、申请列表与审批 |
| 接口契约与验收 | [contract](../src/main/java/contract/README.md) | 统一错误、日志与集成验证 |

Controller、Service、实体和 Repository 按功能就近组织。请求和响应按需使用 `dto`、`vo` 子包。角色与权限定义在 `rolepermission`，管理端共用的 HTTP 入口和用例编排在 `organization`。测试位于 [src/test/java](../src/test/java)，应用配置和 Flyway 脚本位于 [src/main/resources](../src/main/resources)。

运行方式见 [C1 README](../../README.md) 和 [部署运行说明](../../部署运行说明/README.md)。实施范围见 [后端开发规划](../../后端开发规划.md)。
