# 授权配置

状态：员工–角色、角色–权限的授撤权，以及组织停用、重新开放和范围重授接口已实现。参见 [C1 后端开发规划](../../../../../后端开发规划.md) 和 [组织权限停用与重新开放](../../../../../docs/组织权限停用与重新开放.md)。

## 应有功能

负责员工—角色、角色—权限、组织权限开放及停用。

## 实现方式

两类关联用 PUT/DELETE 表达授予和撤销，写入锁定角色行和对应的员工或权限行，组合键防重。C1 的两项管理动作由当前管理员范围授予。Spring Security 检查管理动作，Service 检查目标组织、角色归属、角色已有使用者和权限可用范围。公司管理员管理本公司及下属部门，部门管理员限本部门。局部管理员可分配本级业务权限和上级显式开放的业务权限。全局共享角色与管理权限关系由超级管理员维护。

## 代码入口

[AssignmentService](AssignmentService.java) 处理员工角色和角色权限关系，[OrganizationPermissionService](OrganizationPermissionService.java) 处理组织停用、重开及重授。

## 与其他模块的关键联系

依赖角色与权限定义及员工归属，调用实时授权校验操作者能力。实时授权读取提交后的配置。重授按组织、角色、权限单独记录，停用事务清除受影响的重授记录。共享角色在其他范围内继续按当地规则生效。

## 验收

HTTP 用例覆盖同会话授撤权即时生效、其他有效路径保留、越权操作无写入、重复提交幂等、重新开放后须显式重授，共享角色在其他部门继续生效，以及并发停用、重开和重授后的最终状态。
