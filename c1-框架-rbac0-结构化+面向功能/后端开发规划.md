# C1 后端开发规划

状态：C1 后端已完成本地验收。接口依据 [OpenAPI](./api/openapi.yaml)，运行与验证见 [部署运行说明](./部署运行说明/README.md) 和 [本地验收记录](./docs/本地验收记录.md)。

## 工程结构与模块索引

C1 使用单 Maven 工程 `backend/`，在 `src/main/java` 下按功能模块组织。Controller 处理契约和校验，Service 负责规则和事务，实体与 Repository 归入所属模块。八个模块的入口与详细说明见 [后端模块索引](./backend/docs/模块索引.md)。阶段范围和通用约定见 [C1 阶段需求](./阶段需求与验收.md) 和 [技术规范](../项目整体方向规划和技术细节/RBAC_Technical_Conventions.md)。

## 已确认的业务边界

- 两个独立前端、统一登录入口、同源 Cookie 会话。管理员默认进入管理平台。员工优先进入本部门可用的默认系统，其次进入所属公司可用的默认系统，两者均缺失时显示无可用系统。
- 后端提供默认工作区及下拉选项。下拉只列当前身份可进入的后台和业务系统。系统由路由标识。切换系统保持身份，后端再次验证准入和操作权限。授撤权演示用两个独立浏览器会话。
- 公司、部门、业务系统及模拟申请由初始化提供。公司、部门与系统支持查询，申请支持列表和审批。员工组织归属可维护。组织目录和业务系统定义在 C1 为只读，模拟申请由演示初始化创建。
- 员工删除采用停用。角色和权限存在关联时，先解除关系再删除。超级管理员按组织和系统停用权限。重新开放后，超级管理员恢复默认能力，其他账号须通过组织范围内的角色重授。管理员失去资格时保留已完成的分配。参见 [组织权限停用与重新开放](./docs/组织权限停用与重新开放.md)。
- 公司管理员的管理范围覆盖本公司及下属部门，部门管理员限本部门。超级管理员可进入所有业务系统并执行仍开放的操作。业务操作仍检查记录状态。

## 实施顺序

1. **基础数据。** Flyway V1–V5、JPA、原表导入和演示数据已在隔离 MySQL 验证。
2. **接口闭环。** 登录、审批及两类授撤权已打通。固定路由由 Spring Security 调用统一授权入口检查管理动作，Service 核对目标资源、角色及权限的可管理范围。通用 MVC 错误统一处理。保留同一员工会话的授撤权验收用例。
3. **完整管理功能。** 组织策略、管理查询、对象维护和统一业务日志已实现。员工调岗、两类分配及引用删除共享对应实体锁。组织策略并发和审批依赖故障已通过本地验收。
4. **联调交付。** C1 单机运行见 [部署运行说明](./部署运行说明/README.md)。[前端](./frontend/README.md) 已跑通管理导航、直接授撤权、审批和组织策略。共享环境复验状态见 [阶段需求与验收](./阶段需求与验收.md#外部复验)。

## 当前代码审查与后续改进

已确认审批事务在 Service，关系库访问通过 JPA Repository，API 使用独立响应类型，Flyway V1 至 V5 为增量迁移。并发审批使用条件更新并已测试。保留单 Maven 工程及现有分层。

| 优先顺序 | 发现与处理 |
| --- | --- |
| 授撤权接口 | 路由动作检查、Service 资源范围检查及通用 MVC 错误处理已实现。审批用例已分别验证 Redis 和 MySQL 断连时的 503 及申请数据一致性。 |
| 管理 CRUD | 组织目录和 Excel 清单通过 [CloneFactory](./backend/tools/clonefactory/README.md) 生成映射。员工电话、角色与权限归属等字段显式组装。单请求身份复用和业务系统归属批查仍可优化。 |
| 完整授权配置 | 已验证同一角色路径须覆盖全部适用的重授范围，以及共享角色受停用影响时的组织隔离。C2 扩展候选路径时保留此验证，C3 在候选路径上叠加约束。 |

## 三阶段复用

C2 两版从同一 C1 基线派生，扩展为共同契约，按相同数据验证继承管理、实时有效权限、组织策略联动与申请 CRUD。C3 两条线分别沿用对应 C2，增加约束和可选的会话角色激活。三个阶段继续使用统一登录、默认工作区、系统下拉和审批接口。会话角色激活如纳入 C3，使用独立入口。

参见 [C2 开发方向](<../c2-rbac1-面向功能+面向对象（后端+部分前端）/开发方向细节.md>) 和 [C3 开发方向](<../c3-rbac3-面向功能+面向对象+部分函数式设计（完整前后端）/开发方向细节.md>)。贫血、充血与满血对照安排在 C2 收尾阶段，C3 约束范围由该阶段确认。
